# Функции LeS Forum

## Основные возможности

### Форум
- Создание разделов и подразделов
- Создание тредов с заголовками
- Ответы в тредах
- Загрузка изображений и видео
- Анонимные сообщения
- Поиск по тредам

### Пользователи
- Регистрация и авторизация
- Редактирование профиля
- Смена отображаемого имени
- Загрузка аватарки
- Синие галочки для верифицированных (frnz, Gnrl)

### Уведомления
- Уведомления об ответах
- Счетчик непрочитанных
- Автообновление каждые 30 секунд
- Отметка как прочитанное

### Безопасность и анонимность

#### Шифрование
- AES-256-GCM для контента
- Шифрование паролей
- Обфускация данных в localStorage
- Web Crypto API

#### Защита от отслеживания
- Подмена User Agent
- Фейковые IP адреса
- Обфускация сетевых запросов
- Фейковый трафик в консоли
- Подмена fingerprint браузера
- Рандомизация характеристик устройства

#### Защита от отладки
- Блокировка DevTools
- Отключение контекстного меню
- Блокировка горячих клавиш (F12, Ctrl+Shift+I)
- Детект открытия DevTools
- Очистка консоли

#### HTTP Security Headers
- X-Content-Type-Options: nosniff
- X-Frame-Options: DENY
- X-XSS-Protection
- Referrer-Policy: no-referrer
- Permissions-Policy

### Дизайн

#### Адаптивность
- Десктоп (1200px+)
- Планшеты (768px)
- Мобильные (480px)
- Touch-friendly интерфейс

#### Темы
- Светлая тема (по умолчанию)
- Темная тема (автоматически по системе)
- Минималистичный дизайн
- Плавные анимации

### Медиа
- Поддержка JPEG, PNG, GIF, WebP
- Поддержка MP4, WebM видео
- Автосжатие изображений >2MB
- Максимальный размер 10MB
- Превью перед загрузкой

### База данных
- SQLite для простоты деплоя
- Автоматическое создание таблиц
- Индексы для быстрого поиска
- Транзакции для целостности

### Производительность
- Debounce для поиска
- Throttle для скролла
- Ленивая загрузка изображений
- Минимальный размер бандла
- Нет внешних зависимостей на фронте

## Технический стек

### Backend
- Node.js
- Express.js
- SQLite3
- Multer (загрузка файлов)
- Crypto (шифрование)

### Frontend
- Vanilla JavaScript (без фреймворков)
- CSS3 с переменными
- Web Crypto API
- FileReader API
- Canvas API

### Деплой
- Render.com ready
- Heroku compatible
- Railway compatible
- Vercel compatible (с адаптацией)

## Разделы по умолчанию

- /b/ - Random (Случайное)
- /tech/ - Technology (Технологии)
- /art/ - Art (Искусство)
- /pol/ - Politics (Политика)
- /g/ - Gaming (Игры)

## API Endpoints

### Аутентификация
- POST /api/register - Регистрация
- POST /api/login - Вход

### Пользователи
- GET /api/user/:username - Профиль
- POST /api/user/update - Обновление профиля

### Разделы
- GET /api/boards - Все разделы

### Треды
- GET /api/threads/:board - Треды раздела
- GET /api/thread/:id - Один тред
- POST /api/threads - Создать тред
- DELETE /api/thread/:id - Удалить тред

### Ответы
- POST /api/replies - Создать ответ
- DELETE /api/reply/:id - Удалить ответ

### Уведомления
- GET /api/notifications/:user - Получить уведомления
- POST /api/notifications/read - Отметить прочитанными
