# LeS Forum

Анонимный форум с полным шифрованием

## Деплой на Render

1. Создайте новый Web Service на render.com
2. Подключите репозиторий
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Добавьте переменную окружения `PORT` (автоматически)

## Локальный запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Функции

- Разделы и подразделы
- Анонимные сообщения
- Шифрование данных
- Редактирование профиля
- Синие галочки для верифицированных
- Мобильная адаптация
- Обфускация трафика
- SQLite база данных
